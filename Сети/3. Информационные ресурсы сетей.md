**Информационный ресурс сети** - логически целостная, идентифицируемая совокупность информации, доступная по сети (по URL, пути к файлу, имени БД и т.п.).
## Классификация информационных ресурсов сети

По типу / способу представления:
- Веб‑ресурсы (WWW): сайты, порталы, веб‑приложения.
- Файловые ресурсы: общие папки, репозитории, архивы.
- Базы данных: СУБД, хранилища данных, базы знаний.
- Коммуникационные ресурсы: телеконференции, почтовые архивы, чаты.
- Мультимедийные / потоковые: видео, аудио, трансляции.

По знаковой природе информации:
- текстовые;
- графические;
- числовые;
- звуковые;
- видео;
- смешанные.

По режиму и месту доступа:
- Локального доступа - внутри одной ЛВС / корпоративной сети.
- Удалённого доступа - через WAN / Интернет.

По доступности:
- бесплатные;
- условно‑бесплатные;
- платные;
- закрытые (корпоративные, ведомственные, с ограниченным доступом).

По назначению:
- научные;
- образовательные;
- библиотечные / архивные;
- развлекательные;
- технологические / производственные;
- рекламные / маркетинговые.

По форме свёртывания информации:
- Первичные - исходные документы, данные, записи.
- Библиографические - каталоги, метаданные, указатели.
- Реферативные, обзорно‑аналитические - обзоры, аналитика, отчёты.
