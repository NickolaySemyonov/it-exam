TCP/IP (Transmission Control Protocol/Internet Protocol) - это основной стек протоколов, используемый в современных сетях и интернете. Он работает по принципу инкапсуляции: протокол верхнего уровня работает поверх нижнего, используя его механизмы.
## Уровни стека TCP/IP и протоколы

1. **Канальный уровень (Link Layer)**
	- Ethernet, PPP, Frame Relay
	- Физическая адресация (MAC-адреса)
	- Работа с кадрами (фреймами)
2. **Межсетевой уровень (Internet Layer)**
	- **IP** (Internet Protocol) - маршрутизация пакетов, логическая адресация (IPv4/IPv6)
	- **ICMP** (Internet Control Message Protocol) - управляющие сообщения
	- **ARP** (Address Resolution Protocol) - определение MAC-адреса по IP
	- **IGMP** (Internet Group Message Protocol) - управление групповой рассылкой
3. **Транспортный уровень (Transport Layer)**
	- **TCP** (Transmission Control Protocol) - надёжная доставка с установлением соединения
	- **UDP** (User Datagram Protocol) - быстрая доставка без гарантии
	- RTP, SCTP, DCCP - специализированные транспортные протоколы
4. **Прикладной уровень (Application Layer)**
	- **HTTP/HTTPS** - веб-протоколы
	- **FTP** - передача файлов
	- **DNS** - разрешение доменных имён
	- **SMTP/POP3/IMAP** - электронная почта
	- **SNMP** - управление сетью
