Под **CASE-средствами** *(Computer-Aided Software Engineering)* понимаются инструментальные программные комплексы, предназначенные для автоматизации процессов анализа, проектирования, разработки и сопровождения сложных информационных систем. Главная цель их внедрения - повышение производительности труда разработчиков, улучшение качества кода и документации, а также обеспечение контроля над проектом на всех этапах ЖЦ.

По своему назначению и охвату этапов ЖЦ CASE-средства принято делить на следующие категории:
1. **Средства верхнего уровня (Upper CASE)** - ориентированы на этапы анализа и проектирования. Используются для построения концептуальных моделей предметной области (диаграммы потоков данных, ER-диаграммы, диаграммы вариантов использования).
2. **Средства среднего уровня (Middle CASE)** - охватывают этапы проектирования архитектуры, генерации кода и управления версиями. Обеспечивают связь между моделями и реализацией.
3. **Средства нижнего уровня (Lower CASE)** - автоматизируют непосредственную разработку (генерация программного кода по моделям, компиляция, отладка, тестирование) и реверс-инжиниринг (восстановление моделей из готового кода).
4. **Интегрированные CASE-платформы** - покрывают полный жизненный цикл (от постановки задачи до сопровождения) и объединяют в себе все перечисленные функции через единый репозиторий.

Обычно к CASE-средствам относят любое программное средство, автоматизирующее ту или иную совокупность этапов ЖЦ ПО и обладающее основными характерными особенностями.  
Это:
- мощные графические средства для описания и документирования ИС, обеспечивающие удобный интерфейс с разработчиком и развивающие его творческие возможности;
- интеграция отдельных компонентов CASE-средств, обеспечивающая управляемость процессом разработки ИС;
- использование специальным образом организованного хранилища проектных метаданных (репозитория).

## Примеры популярных CASE-средств

| **IBM Rational Rose**                      | классический инструмент для визуального моделирования на UML (Upper/Middle CASE)                                                         |
| ------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| **Sparx Enterprise Architect**             | мощная платформа полного цикла (поддержка UML, SysML, генерация кода, реверс-инжиниринг)                                                 |
| **ERwin Data Modeler**                     | специализированное средство для проектирования баз данных (модели «сущность-связь»).                                                     |
| **AllFusion Modeling Suite** (ранее BPwin) | инструмент для функционально-стоимостного анализа и описания бизнес-процессов (нотация IDEF0).                                           |
| **Visual Paradigm**                        | современный инструмент с поддержкой Agile-методологий, сквозным отслеживанием требований и интеграцией с популярными средами разработки. |
| **Astah Professional**                     | легковесный CASE-инструмент для UML, требований и ER-диаграмм                                                                            |
